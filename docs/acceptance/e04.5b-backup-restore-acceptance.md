# Signal Observatory — E04.5B Backup / Restore Acceptance

## Decision

**PASS — accepted on 2026-08-12 UTC.**

E04.5B now provides a complete, checksummed recovery unit for PostgreSQL, immutable Raw,
Registry configuration, and provenance. A real backup was created from the running Observatory,
fully verified, restored into isolated empty targets, checked through lineage and API interfaces,
and cleaned up.

This decision does not complete or alter the independent E03 seven-day scheduler soak or E04
cross-day acceptance window.

## Implemented controls

- strict versioned Pydantic manifest/report schemas with unknown-field rejection;
- unique UTC backup identifiers;
- PostgreSQL repeatable-read exported snapshot followed by official `pg_dump -Fc`;
- client/server major-version compatibility check and `pg_restore --list` validation;
- deterministic immutable Raw copy with compressed JSONL manifest and byte/source checksums;
- Registry YAML snapshot and both tree/projection checksum verification;
- `.tmp/<backup-id>` staging and atomic publication only after verification;
- portable logical Raw paths, including migration `20260812_0006` for existing pointers;
- explicit empty-target restore with no overwrite or force path;
- exact count, migration, Registry, Raw, lineage, and API post-restore verification;
- isolated disaster-recovery drill with persisted report and automatic cleanup;
- read-only Data Protection status in `/api/operations` and the Operations page;
- operator guide, ADR-019 through ADR-021, and repository safety rules.

### Windows path-length finding

The first drill, `signal_observatory_restore_drill_20260812121041_7b5a48`, safely failed before
database restore because a deeply nested workspace path exceeded the Windows legacy path limit.
The failure report was preserved, the isolated database was dropped, and no active data changed.
The drill workspace was moved to the shorter system temporary path and errors were bounded so a
filesystem exception cannot flood CLI JSON. The second drill above then passed completely. This is
retained as evidence that failed drills remain observable and safe.
